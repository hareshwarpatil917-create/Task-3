# CSS Challenge

## Objective

This project was created as part of the Web Development Internship Task 3. The goal is to practice CSS Flexbox, CSS Grid, responsive design, and simple animations by building clean and responsive UI components.

---

## Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Grid

---

## Features Implemented

### Flexbox Layout
- Three feature cards displayed in a single row on desktop.
- Cards automatically stack vertically on smaller screens.
- Proper spacing using Flexbox properties.
- Smooth hover effect on each card.

### Grid Layout
- Responsive service section with six cards.
- CSS Grid using `repeat()` for equal columns.
- Consistent spacing and alignment.
- Automatically adjusts for smaller screen sizes.

### Animation
- Smooth card hover animation using `transition` and `transform`.
- Soft shadow effect for better user interaction.
- Simple and professional animation without excessive motion.
